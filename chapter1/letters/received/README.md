# Letters of support — register

The originals are in `incoming/` and `incoming/letters/`. Each `.md` here holds the text as
returned, with a note on what it commits the writer to and what still needs fixing.

Wiley's reviewers receive the letters as one bundle. Most of them name neither the book nor
us, so the bundle needs a cover sheet that gives the title and the editors and lists the
letters. A letter that cannot be read without that sheet is still usable.
