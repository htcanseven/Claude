# Manuscript: Alternative-dependent diagnosability (Research in Engineering Design)

## Build

```bash
cd paper
latexmk -pdf main.tex        # pdflatex + bibtex, three passes
```

Requires TeX Live with `sn-jnl.cls` (included here), natbib, booktabs, tikz, siunitx, manyfoot.

## Layout

| Path | Content |
|---|---|
| `main.tex` | class options, title page, declarations, appendices |
| `sections/*.tex` | abstract, intro, background, method, demo, results, discussion, conclusion |
| `sections/tab_*.tex`, `sections/appendix_tables.tex` | generated by `scripts/make_tables.py` from `results/tables/*.csv` (do not edit by hand) |
| `figures/*.pdf` | copied from `results/figures/` (vector) |
| `refs.bib` | references, author-year style (`sn-chicago` option of `sn-jnl`) |
| `review/` | frozen pre-review PDF, reviewer reports, response to reviewers, change log |

## Regenerating tables and figures

```bash
PYTHONPATH=scripts python3 scripts/compare3.py      # three-alternative results
PYTHONPATH=scripts python3 scripts/sensitivity.py   # sensitivity + bootstrap
python3 scripts/sensor_suites.py                    # suites, PMSG/SCIG
python3 scripts/make_tables.py                      # LaTeX tables
cp results/figures/*.pdf paper/figures/
```

## Submission switches

* `\anontrue` in `main.tex` removes the author block for a blinded copy.
* Funding, ORCID and the final code DOI are entered in the editorial system; check the
  `Funding` and `Code availability` declarations before upload.
