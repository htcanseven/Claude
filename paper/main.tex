\author{H\"useyin Tayyer Canseven}
\ead{huseyin.canseven@lut.fi}

             city={Lappeenranta},

\begin{abstract}
Detection methods for incipient stator-winding faults are developed one machine at a time, so how the generator type changes the problem is not quantified, and the detectability measures of fault-detection theory presuppose a model or a trained detector. A statistic that requires neither is proposed, the signal-to-drift ratio (SDR): the relative change of a feature between a healthy reference interval and a faulted interval, divided by a quantile of its changes between adjacent healthy intervals, the known-onset mean-shift test as a standardised effect size calibrated on each machine's own healthy non-stationarity. From it follow a minimum detectable extent, a detectable share and a signature location per machine type, sensor suite and fault class; a decision table selects the cheapest suite that meets a requirement with a stated power and bootstrap confidence; and a transfer test fixes the feature-referencing rule under which a detector serves several machine types. On open laboratory-bench data from permanent-magnet, squirrel-cage induction and wound-field synchronous generators with the same tapped short-circuits, the same design-level fault is three different physical events, phasor residuals remove a faulted-phase dependence of the magnitude ratios, the signature relocates between terminal voltage, controller states and field current with the machine--drive combination, the cheapest adequate suite depends on machine type and requirement, and a learned detector transfers once its features are referenced to the target machine's healthy behaviour. Code and data are open.
\end{abstract}

\section{Introduction}\label{sec:intro}

Stator-winding insulation faults are the archetypal incipient failure of an electrical machine: a short-circuit across a few turns whose subtle signature evolves into a machine-destroying fault if it is not detected \citep{RieraGuasp2015}. Electrical-subsystem failures contribute substantially to wind-turbine downtime \citep{Tavner2007}, and a rich literature detects winding faults in a given machine \citep{Thomson2001, Kliman1996, Lee2003, Nandi2005, Tallam2007, Tallam2003, Cruz2004}, almost all of it validated on one machine. Yet the generator type of a large turbine---permanent-magnet synchronous (PMSG), squirrel-cage induction (SCIG), wound-field synchronous (WFSG) or doubly-fed induction---is chosen on cost, mass, efficiency and grid-compliance grounds \citep{Polinder2013}, and its condition monitoring is added afterwards from commercial systems \citep{Yang2014}. Whether the same fault is equally visible in different generator types, in which measured quantity it appears, and which sensors are therefore worth specifying for each has not been quantified.

Such questions need a measure of detectability that requires neither a model of the machine nor a trained detector, is comparable across features, operating points and machines, and connects to the quantities a monitoring specification is written in: the smallest fault to be detected, the false-alarm rate tolerated and the sensors it costs. The detectability notions of fault detection and isolation (FDI) theory \citep{Basseville2001, Blanke2016, Krysander2008} and the sensor-placement methods built on them \citep{Frisk2009} presuppose a model; a learned detector \citep{Lei2020} presupposes data from the very machine, and its transfer across machines is an open problem \citep{Pan2010}.

This paper proposes the signal-to-drift ratio (SDR): the relative change of an observable feature between a healthy reference interval and a faulted interval, divided by a quantile of the relative changes the same feature exhibits between adjacent healthy intervals when nothing is wrong. It is the known-onset mean-shift test of change detection \citep{Basseville1993} as a standardised effect size; an SDR of one marks the point at which a fault of a given extent becomes distinguishable from the ordinary non-stationarity of the healthy machine at a chosen per-trial false-alarm rate. From it follow a \emph{minimum detectable extent} (MDE), a \emph{detectable share} (DS) above a required extent and a \emph{signature location} per machine type, sensor suite and fault class, a decision table that selects the cheapest adequate suite, and a transfer test that fixes the feature-referencing rule under which a detector built on one machine type serves another. The question is made answerable by open benchmark datasets \citep{Tominaga2025pmsg, Tominaga2025scig, Tominaga2024gen} in which a PMSG, an SCIG and a variable-speed WFSG were subjected to the same inter-turn and inter-winding short-circuits at the same tapped positions of the stator winding, the PMSG and SCIG on one bench with one converter, controller and protocol.

The contributions are the SDR with its screen, calibrated oracle and derived quantities, evaluated on the physically distinct fault sizes of a test matrix rather than on its nominal extents; a procedure that turns them into a decision table with bootstrap confidence and a transfer test over referencing rules; and the first quantitative comparison known to the author of winding-fault detectability across three generator types, with four findings: the design-level extent and the physical severity of a fault are different axes, and the faulted phase rides on the nominal extent axis unless sequence quantities are taken as phasor residuals; the measurement group in which a fault appears depends on the machine--drive combination; the cheapest adequate suite depends on the machine type \emph{and} on the requirement; and a learned detector transfers once its features are referenced to healthy behaviour of the target machine. Open code reproduces every result from the public data.

\section{Background and related work}\label{sec:background}

Fault detection and isolation has a mature theory of diagnosability for modelled systems: structural analysis determines which faults are detectable and isolable from which sensor sets \citep{Blanke2016, Krysander2008}, sensor placement selects the cheapest adequate set \citep{Frisk2009}, and \citet{Basseville2001} defines detectability as a distance between the residual distributions under the healthy and the faulted hypothesis; all presuppose a trusted model. Data-driven diagnosis \citep{Lei2020} replaces the model by data from the very machine, with transfer across machines an active problem \citep{Pan2010}, and prognostics grades features by monotonicity and trendability \citep{Coble2013} or by separability measures such as the per-feature area under the receiver operating characteristic curve (AUC) \citep{Hanley1982}. The SDR belongs to that family, with the sensitivity index $d'$, the fault-to-noise ratio of model-based FDI and the per-feature AUC; what is new is its null, the drift of each feature between adjacent healthy intervals of every trial, which fixes the false-alarm rate of the simplest detector and makes the magnitude comparable across features, operating points and machines, together with the screen, the limit-of-detection quantities and their use to compare machine types and sensor suites. It stops at detectability, which isolation, severity estimation and prognosis presuppose.

Inter-turn short-circuits are among the most studied incipient faults in electrical machines \citep{RieraGuasp2015, Zafarani2018}. Negative-sequence methods \citep{Kliman1996, Arkan2001, Lee2003}, the extended Park's vector approach \citep{Cruz2001} and the reviews \citep{Nandi2005, Tallam2007, Henao2014} have established the signatures: a winding asymmetry produces negative-sequence components in the terminal quantities and a component at twice the fundamental frequency in the synchronous frame, and because the fault-induced negative-sequence phasor adds to the inherent asymmetry of the machine, the detection quantity is the change of that phasor rather than of its magnitude \citep{Kliman1996, Arkan2001}. Under closed-loop current control the asymmetry migrates into the voltage commands and controller states to a degree set by the current-loop bandwidth relative to twice the electrical frequency \citep{Tallam2003, Cruz2004, Cheng2011}; in a wound-field machine the stator negative sequence induces a component at twice the electrical frequency in the field current \citep{Neti2009}, and in permanent-magnet machines with an accessible neutral the zero-sequence voltage is a sensitive indicator \citep{Urresty2012, Hang2015}. These facts have not been turned into a measure applicable across candidate machine types; learned detectors are developed for one machine \citep{Canseven2026machines}, and finite-element turn-fault models \citep{Vaseghi2009} are the natural trial generators before hardware exists.

\section{Method}\label{sec:method}

\subsection{Definitions and terms}\label{sec:defs}

Let $\mathcal{A}$ be a set of candidate \emph{alternatives}, each a machine type with the control structure it implies; $\mathcal{F}$ a set of failure-mode classes, each parameterised by a design-level \emph{extent} $e\in E_f$ realisable in every alternative (for a winding fault, the fraction of a branch that is short-circuited); $\mathcal{S}$ a set of \emph{sensor suites}, each a set of measurements, including quantities internal to the drive controller, with a cost $c(s)$ and the set $\Phi(s)$ of features computable from them; and $\mathcal{O}$ the operating envelope, discretised into operating points $o$. Because the design-level extent does not fix the physical severity of the event (Section~\ref{sec:res-severity}), a \emph{physical severity axis} is declared beside it. A \emph{trial} is a record of alternative $a$ at operating point $o$ with a healthy reference interval $R$ immediately followed by a faulted interval $F$ in which $(f,e)$ is present; trials may come from a physical test or from a validated simulation (Section~\ref{sec:scope}).

\subsection{The signal-to-drift ratio}\label{sec:sdr}

The reference interval is split into two adjacent halves $R_1, R_2$, with $R_2$ adjacent to $F$. For a feature $\varphi\in\Phi(s)$ and a trial, let $\bar\varphi_{R_1}, \bar\varphi_{R_2}, \bar\varphi_F$ be its mean values over the intervals and define the relative change under fault, referenced to the half adjacent to the fault, and the relative change between the two healthy halves,
\begin{equation}
  \delta_\varphi = \frac{\bar\varphi_F - \bar\varphi_{R_2}}{|\bar\varphi_{R_2}|}, \qquad
  \delta^0_\varphi = \frac{\bar\varphi_{R_2} - \bar\varphi_{R_1}}{|\bar\varphi_{R_1}|}.
  \label{eq:delta}
\end{equation}
$\delta^0_\varphi$ measures how much the feature moves when nothing is wrong: sensor noise, drift of the operating point, controller activity, thermal effects. It is available from every trial of alternative $a$, faulted or not, and its absolute value pooled over the $N_a$ trials forms the empirical null of ordinary non-stationarity for that alternative and feature. The signal-to-drift ratio is
\begin{equation}
  \mathrm{SDR}_\varphi = \frac{|\delta_\varphi|}{q_\alpha\!\left(|\delta^0_\varphi|\right)},
  \label{eq:sdr}
\end{equation}
where $q_\alpha$ is the $\alpha$-quantile of the pooled null; with $\alpha=0.95$, $\mathrm{SDR}_\varphi\ge1$ means that the change under fault exceeds what the healthy system produces on its own in 95\,\% of comparable interval pairs. For sequence quantities, whose fault-induced phasor adds to the inherent asymmetry of the machine, $\varphi$ is the complex phase-referenced negative-sequence ratio and the changes are magnitudes of complex differences (\ref{app:features}).

The SDR is a mean-shift statistic with a known change time, studentised by an empirical quantile of its own drift null: for a zero-mean Gaussian null $q_{0.95}(|\delta^0|)=1.96\,\sigma_{\delta^0}$ and $\mathrm{SDR}\ge1$ is a two-sided 5\,\% test on the shift of interval means, the fixed-sample, known-onset case of the generalised likelihood ratio of \citet{Basseville1993}; the quantile is kept because the null has an excess kurtosis of up to 7 here, and its sampling variability (a factor 1.3 to 1.5 at 95\,\%) enters every interval reported. In signal detection the SDR is the sensitivity index $d'$ against the drift distribution; in model-based FDI it is the fault-to-noise ratio of \citet{Basseville2001} with the noise scale taken from the healthy records. With a known onset, a whole faulted interval averaged and a reference immediately before the fault, the SDR characterises the simplest detector on the feature, an abrupt-onset threshold at a stationary operating point against a null of sub-second non-stationarity; a detector that combines features or accumulates evidence can detect below $\mathrm{SDR}=1$, which is why the calibrated oracle and the transfer experiment are part of the method, and Section~\ref{sec:res-robust} quantifies the wider null of a commissioning reference. Because a quieter null raises the SDR as much as a stronger signature does, numerator and denominator are reported separately when alternatives are compared (Section~\ref{sec:res-where}).

\emph{Safeguards.} (i) On healthy trials, in which the ``faulted'' interval contains only the switching operation, a feature should exceed $\mathrm{SDR}=1$ at the nominal rate $1-\alpha$; a feature whose false-alarm count in the $n_h$ healthy trials is incompatible with that rate (one-sided binomial test at the 5\,\% level; three or more of nine at $\alpha=0.95$) or whose null quantile exceeds one is excluded for that alternative. With nine healthy trials the screen has little power (a true rate of 20\,\% passes with probability 0.74), so the false-alarm count of every fixed feature is reported. (ii) A suite is evaluated by one \emph{fixed} feature, chosen once among its screened features by the smallest minimum detectable extent, then the detectable share, then the median SDR, or by the \emph{oracle} feature, the best feature of each trial, at a calibrated threshold, the $\alpha$-quantile of $\max_\varphi |\delta^0_\varphi|/q_\alpha(|\delta^0_\varphi|)$ over all records, because a maximum over $k$ features exceeds the single-feature threshold at a rate of up to $1-\alpha^k$. (iii) Every design quantity carries a bootstrap interval, over tap pairs for statements about a class and over operating points within an extent level for the MDE, with the null quantile re-estimated in every resample.

\subsection{Derived quantities}\label{sec:derived}

For each alternative $a$, suite $s$ and class $f$: the \emph{diagnosability map} $D_a(s,f,e,o)$ is the SDR of the suite's fixed feature at extent $e$ and operating point $o$; the \emph{minimum detectable extent} $\mathrm{MDE}_a(s,f)$ is the smallest tested extent level $e^\ast$ such that $\operatorname{median}_o D_a(s,f,e,o)\ge1$ for every tested $e\ge e^\ast$, reported as the bracket $(e^-, e^\ast]$ between the last undetected and the first detected level, the levels being the physically distinct fault sizes of the test matrix (Section~\ref{sec:extent}); the \emph{detectable share} $\mathrm{DS}_a(s,f\mid e\ge e_{\mathrm{req}})$ is the fraction of faulted trials with $e\ge e_{\mathrm{req}}$ in which $\mathrm{SDR}\ge1$; and the \emph{signature location} is the measurement group---stator currents, terminal voltages, controller internals, mechanical quantities, excitation---whose best screened feature attains the highest SDR in the largest share of trials. For a requirement $(f, e_{\mathrm{req}}, \alpha)$ the \emph{adequate} suites of an alternative are those with $\mathrm{MDE}\le e_{\mathrm{req}}$ and a detectable share above the requirement of at least a stated power; the signature location tells the designer \emph{why} an alternative behaves as it does.

The procedure (Fig.~\ref{fig:method}) has six steps; steps 3--4 are fixed by Eqs.~(\ref{eq:delta})--(\ref{eq:sdr}), the others are design decisions with default rules.
\begin{enumerate}
  \item \textbf{Frame.} Enumerate $\mathcal{A}$, the classes $\mathcal{F}$ with an extent scale realisable in every alternative and a physical severity axis, the suites $\mathcal{S}$ ordered by cost (an ordinal rank by added hardware and integration by default) and the envelope $\mathcal{O}$; set $e_{\mathrm{req}}$ as the smallest extent whose growth to an unacceptable consequence outpaces the inspection interval and $1-\alpha$ as the per-trial false-alarm rate tolerated.
  \item \textbf{Generate trials.} For each $(a,f,e,o)$ obtain trials with a healthy reference of at least twice the faulted duration immediately followed by the fault, covering at least the levels that bracket $e_{\mathrm{req}}$ and the corners of the envelope, plus healthy trials with the same timing for the screen.
  \item \textbf{Compute.} Extract $\Phi(s)$ on sliding windows within the intervals, form the pooled null per alternative and feature, compute the SDR per trial, apply the screen.
  \item \textbf{Map.} Build $D_a(s,f,e,o)$ and summarise it into $\mathrm{MDE}_a$, $\mathrm{DS}_a$ and the signature location for the fixed and oracle variants, with bootstrap intervals.
  \item \textbf{Select.} Build the decision table: for each alternative, class, suite and candidate $(e_{\mathrm{req}}, \alpha)$, classify the suite as \emph{meets} when the bootstrap probability of the joint event $\{\mathrm{MDE}\le e_{\mathrm{req}}$ and $\mathrm{DS}(e\ge e_{\mathrm{req}})\ge\mathrm{DS}_{\mathrm{req}}\}$ is at least 0.95, \emph{fails} when it is at most 0.05 and \emph{uncertain} otherwise, $\mathrm{DS}_{\mathrm{req}}$ being the power the requirement demands (0.9 here); the fixed feature is re-selected and the null re-estimated in every resample, a suite's verdict is at least that of its subsets, and $e_{\mathrm{req}}$ takes the tested levels, because between levels the MDE is only a bracket. The adequate suite is the cheapest that meets the requirement for every class; the choice of machine type is affected only when no affordable suite meets it for some alternative.
  \item \textbf{Assess transfer.} If the detector must serve a family of alternatives, test it across them under candidate feature-referencing rules; the rule that transfers enters the specification.
\end{enumerate}

\subsection{Design-stage instantiation and scope}\label{sec:design-stage}\label{sec:scope}

Before hardware exists the two ingredients of the SDR are supplied separately: the numerator by a finite-element or circuit model of each alternative with the fault injected \citep{Vaseghi2009}, validated on a few physical trials, the denominator from measured healthy records of hardware of the same class, on the testable assumption that the healthy non-stationarity depends on the sensing and control chain more than on the machine (Section~\ref{sec:res-where} compares two machines on one bench). The method applies to classes that can be seeded at a known extent, at a stationary operating point, with a healthy interval immediately before the fault, in every alternative; it evaluates a threshold on interval means, not the time to detection; and $1-\alpha$ is a per-decision rate, at one decision per interval (0.36\,s here) a false alarm every 7\,s for $\alpha=0.95$, so the MDEs reported are bench limits of detection, not field thresholds, and a field monitor needs an accumulation rule over many decisions. Run-to-failure data, with no healthy interval before a known onset, do not fit the trial structure.

\section{Demonstration on three wind-turbine generators}\label{sec:demo}

\subsection{Alternatives and data}\label{sec:data}

The three alternatives are laboratory-scale generators on instrumented test benches at the University of S\~ao Paulo, published as open benchmark datasets (Table~\ref{tab:alternatives}, Fig.~\ref{fig:alternatives}). The PMSG \citep{Tominaga2025pmsg} and the SCIG \citep{Tominaga2025scig} are four-pole, 230\,V, double-star machines from the same manufacturer, rated 2.5\,kVA and 2.5\,kW, on the \emph{same} bench: the same prime mover, converter, control platform and field-oriented control (FOC; rotor angle from an encoder for the PMSG, from a flux observer for the SCIG), sensors, acquisition (20\,kHz, 3\,s records), fault-insertion hardware and test script, so that everything but the machine and the control structure it requires is held fixed. The variable-speed WFSG \citep{Tominaga2024gen} is a 2\,kVA four-salient-pole machine on an earlier bench of the same group \citep{Rocha2023} with a three-level converter, FOC with encoder angle, 4\,kHz acquisition and 1.3\,s records: the same tapped short-circuits on a different bench, whose fault resistances, fault durations, converter, sampling rate and voltage sensing all differ and whose variable-speed dataset holds no healthy records, so that the screen and the nuisance-transient negatives are unavailable for it; it is analysed as a third case at matched extents with those differences kept explicit. The data papers do not state the current-loop gains, the switching frequencies, the flux-observer structure or the transducer bandwidths.

\subsection{Failure-mode class and extent scale}\label{sec:extent}

All three machines have 24 tapped derivation points at the same relative positions of their stator windings, so that a short-circuit between two taps realises a fault of known extent in every alternative. Two classes are used (Fig.~\ref{fig:faults}): inter-turn short-circuits (both taps on one branch) and inter-winding short-circuits (taps on the two parallel branches of a phase); the extent $e$ is the fraction of a branch between the taps, 2.7--12.1\,\% for the twelve inter-turn and 2.3--40.2\,\% for the twelve inter-winding cases. The nominal extents overstate the resolution of the matrix: the fault current of a resistor-limited short-circuit is set by the voltage induced in the shorted turns, so tap pairs with equal fault currents short the same number of turns and are the same physical fault (on the PMSG the four pairs of each inter-turn level carry fault currents within 3\,\% of each other, 1.4, 3.8 and 6.0\,A; the SCIG currents cluster identically). The limit-of-detection quantities are therefore evaluated on \emph{physical extent levels}, tap pairs of one class whose median fault currents, normalised per machine and averaged over the two machines, lie within 7\,\% of the first pair of the level: three inter-turn levels (2.7--3.8, 7.4--7.7 and 11.6--12.1\,\% of a branch) and six inter-winding levels (2.3--3.2, 9.7--10.6, 14.3--14.8, 21.7--22.2, 33.7--37.5 and 40.2\,\%). The tap layout has a second property that matters for sequence features: the four smallest inter-turn pairs lie in phase A, the 7.4--7.7\,\% pairs in phases A and B and the largest in phases A and C, so on the nominal extent axis the faulted phase is confounded with the extent (Section~\ref{sec:res-phase}). Faults were closed through a contactor and a series resistance at steady state, 2.6\,$\Omega$ for 0.4\,s on the PMSG and SCIG and 1 to 11.32\,$\Omega$ on the WFSG, where the resistance was raised with extent, so that extent and impedance are confounded on that bench; the resistance being of the order of the winding impedance of these small machines, the severity is \emph{resistor-limited}, unlike a bolted fault, which the leakage reactance of the shorted turns limits.

\subsection{Sensor suites and features}\label{sec:suites}

Five sensor suites are considered, ordered by the data access, hardware and integration they add to a bare generator--converter set (Table~\ref{tab:suitedef}): \emph{drive-internal} uses only quantities the converter controller already has; \emph{3\,CT} uses the three phase currents with angle-free features, so that its cost is data access rather than hardware; \emph{3\,CT + 3\,VT} adds three terminal voltage transducers (VT); \emph{3\,CT + 3\,VT + drive} adds controller access; and \emph{+ torque transducer} adds a shaft torque sensor. For the WFSG the field current is an additional drive-internal observable (the \emph{excitation} suite), available because its exciter is static \citep{Neti2009}. Each feature is assigned to the cheapest suite whose measurements suffice to compute it. Sequence quantities enter in two forms: the magnitude ratios $I_2/I_1$, $V_2/V_1$ and $D_2/D_1$ of currents, terminal voltages and duty cycles, the established indicators \citep{Kliman1996, Lee2003, Cruz2001}; and the phasor residuals $|\Delta\bar I_2|/I_1$, $|\Delta\bar V_2|/V_1$ and $|\Delta\bar D_2|/D_1$, the magnitude of the change of the complex negative-sequence component referenced to the positive-sequence angle (\ref{app:features}), which isolates the fault-induced part whatever the faulted phase \citep{Kliman1996, Arkan2001}. Zero-sequence voltage, stray flux, temperature, vibration and partial discharge are not recorded. Features are computed on sliding windows of $n_c$ electrical cycles with a hop of one cycle; the electrical frequency and the phase rotation are estimated per window from the current space vector, so that the external suites need no angle sensor.

\subsection{Computation}\label{sec:computation}

For the PMSG and SCIG the reference interval is the 0.68\,s before the contactor command, split into $R_1$ (0.32\,s) and $R_2$ (0.36\,s); for the WFSG the fault interval is located from the measured fault current and the reference interval (0.49\,s) is split at 0.30\,s (interval boundaries in \ref{app:computation}). The main PMSG--SCIG comparison uses $n_c=5$; the three-alternative comparison uses $n_c=3$ because the WFSG fault intervals are short; the sensitivity of every conclusion to $n_c\in\{3,5,8\}$ and $\alpha\in\{0.90,0.95,0.99\}$ is reported, with the screen applied at each setting. The null is pooled over all 225 records of each of the PMSG and SCIG and over the 438 WFSG records. Bootstrap intervals use 2000 resamples: the median SDR and the detectable share of a class are resampled over the twelve tap pairs, the same pairs for both machines so that the SCIG/PMSG ratio is matched, the MDE over the operating-point trials within each extent level, and in every resample the null quantile is re-estimated from a cluster resample of the machine's 25 clusters (24 tap pairs and the healthy set); the decision table uses 1000 resamples per suite, alternative, class and $\alpha$, with $e_{\mathrm{req}}$ at the tested levels and a required detectable share of 0.9.

Step~6 is instantiated as a window-level change detector: a gradient-boosted decision-tree (GBDT) classifier \citep{Friedman2001} and, for the PMSG--SCIG pair, a logistic regression, trained to separate faulted windows from healthy ones, within an alternative by five-fold cross-validation grouped by tap pair and across alternatives by training on all trials of one machine and testing on all trials of another. Four feature-referencing rules are compared: physical units; features $z$-scored on all healthy trials of the target machine (a commissioning baseline); $z$-scored on the healthy trial at the same operating point; and the absolute $z$-score of each window against the \emph{first half} of its own trial's reference interval, the operational form of the SDR's referencing assumption. Negatives are the reference and recovery windows of all trials plus the fault-interval windows of the healthy trials, the only negatives that contain the contactor operation without a fault; because the normalising windows are trivially separable under the fourth rule, every metric is reported on the out-of-reference windows, with 95\,\% intervals from a cluster bootstrap over the tested machine's trials (settings in \ref{app:computation}).

\section{Results}\label{sec:results}

\subsection{The same design-level fault is not the same physical fault}\label{sec:res-severity}

For the same tap pair the SCIG's fault current is about 10\,\% lower than the PMSG's (medians 3.3 against 3.7\,A for inter-turn and 7.7 against 8.5\,A for inter-winding pairs), but relative to what the stator sensors see the difference is larger: the fault current is 1.45 times the pre-fault stator current (RMS, median over pairs) in the PMSG and 0.63 times in the SCIG for inter-turn faults, and 3.3 against 1.5 times for inter-winding faults, because the SCIG's stator current carries the magnetising component (5.3 against 2.6\,A RMS before the fault); the WFSG trials at the matching impedance give 1.20 and 1.03. A fault specified as ``$e$\,\% of a winding'' therefore arrives at the sensors of the three alternatives as three different physical events. The physical severity axis, the RMS fault current relative to the RMS stator current, orders faults of equal turns correctly because the MMF asymmetry of a turn fault scales with the fault current times the shorted fraction; across levels it is a measured, not a general, severity scale, and being resistor-limited it scales with volts per turn and speed.

\subsection{Where the signature appears, and why the SDR differs}\label{sec:res-where}

The null of the SDR differs between the PMSG and the SCIG on every feature, and by how much depends on the form in which the feature is written: in the relative form of Eq.~(\ref{eq:delta}) the SCIG's null is 2.4 times quieter than the PMSG's for the voltage residual, 5.2 times for the current residual and 45 times for the $d$-axis current ripple; in the units of the features themselves the factors are 1.1, 6.0 and 7.0, because the SCIG's $d$-axis ripple has a healthy level five times the PMSG's, its stator current carrying the magnetising component. The decomposition therefore reads differently for the three measurement groups: through the terminal-voltage residual the machines are equivalent, numerator and null agreeing in volts to within 20\,\%; through the stator-current residual the SCIG's SDR is 3.7 and 3.3 times the PMSG's while the PMSG's current change is the larger in both forms, so there the SCIG wins entirely by a quieter null; through the $d$-axis features the SCIG's SDR is 16 and 23 times the PMSG's and in absolute units the SCIG has both the larger signature and the quieter null. The reading that the SCIG wins only by silence thus holds for the stator current and is, for the controller quantities, an artefact of the relative normalisation; nor is the null a property of the transducers alone, since the duty-cycle residual, a controller output, has a null 8.5 (relative) and 3.1 (absolute) times larger on the PMSG.

Fig.~\ref{fig:features} shows the median SDR of every feature for the three alternatives. In the PMSG the terminal-voltage group carries the strongest signature in 94\,\% of inter-turn and 97\,\% of inter-winding trials, through the voltage residual (median SDR 6.8 and 53 at five-cycle windows; 88 and 100\,\% of trials detectable), and the stator-current residual is weak for inter-turn faults (1.7; 70\,\%). In the SCIG the controller group is strongest in 63 and 67\,\% of trials, through the duty-cycle residual for inter-turn faults (11.2; 93\,\%) and the $d$-axis ripple and its PI output for inter-winding faults (68; 100\,\%), the stator-current group in 34 and 33\,\%; the two machines rank the 33 common features with a Spearman correlation of 0.74 and 0.82. In the WFSG the terminal-voltage and current residuals, the commanded $q$-axis voltage and the field-current 2$f_e$ ripple, an observable the other two lack, are strongest; the field current detected 80\,\% of the inter-turn trials at the matching impedance and all inter-winding trials. The physical quantity behind the relocation is the incremental negative-sequence impedance at the terminals, $\Delta\bar V_2/\Delta\bar I_2$ per trial: 12.7 [11.1, 14.1]\,$\Omega$ (inter-turn) and 12.2 [10.2, 13.2]\,$\Omega$ (inter-winding) in the PMSG against 7.3 [6.9, 7.7] and 7.4 [7.2, 7.6]\,$\Omega$ in the SCIG (medians and interquartile ranges), 0.60 and 0.35 per unit on the 2.5\,kVA, 230\,V base, so the PMSG drive converts a negative-sequence current disturbance into 1.7 times the terminal voltage that the SCIG drive does; the contribution of the current regulator, which raises the closed-loop negative-sequence impedance \citep{Tallam2003, Cheng2011}, cannot be separated from the machine's own without the undocumented drive parameters. Both machines run the same field-oriented controller but differ in angle source, negative-sequence impedance and healthy baselines, so the relocation belongs to the machine--drive combination, not to the control structure alone.

\subsection{The faulted phase and the extent axis}\label{sec:res-phase}

The inter-turn test matrix carries a second variable on its nominal extent axis: the four pairs of the smallest level lie in phase A, those of the middle level in phases A and B, those of the largest in phases A and C. Fig.~\ref{fig:pairs} shows why this matters: the magnitude ratios $V_2/V_1$ and $I_2/I_1$ depend on the faulted phase far beyond what the extents explain (the spread between the pairs of one level is a factor 2.7 to 14 for $V_2/V_1$ and 1.3 to 7 for $I_2/I_1$), whereas the phasor residuals remove this almost entirely, the pairs of every level agreeing to within a factor 1.1 to 1.8 on both machines. The mechanism is the one of Section~\ref{sec:suites}: the inherent negative-sequence component of each machine (healthy $V_2/V_1$ of 0.0009 on the PMSG and 0.0020 on the SCIG) is of the same order as the fault-induced one for a small inter-turn fault, so the magnitude of their sum rises or falls with the angle between them, which rotates by $\pm120^\circ$ with the faulted phase; the complex change does not. Hence the residual features represent the suites wherever a sequence quantity is used (Tables~\ref{tab:mde}--\ref{tab:decision}), the magnitude ratios remaining in Fig.~\ref{fig:features} as the established indicators; and on the residual features the two machines on the common bench are nearly indistinguishable through the terminal voltage, with per-level medians of $|\Delta\bar V_2|/V_1$ of 1.1, 6.8 and 19.5 (PMSG) against 0.9, 6.9 and 19.5 (SCIG) at the three inter-turn levels, and differ through the stator current, where the SCIG's residual is 2 to 4 times the PMSG's: the relocation of the signature survives the change of feature, the earlier reading that the PMSG's voltage signature is stronger than the SCIG's does not.

\subsection{Operating envelope, robustness and the two nulls}\label{sec:res-robust}\label{sec:res-op}

Speed dominates the operating-point dependence: between 1200 and 1800\,rpm the median inter-turn SDR of the fixed features rises by a factor of 1.3 to 4.4 and the detectable shares from 69--78 to 83--100\,\%, while torque changes the medians by less than a factor 1.25 at a fixed speed; the dependence is consistent with a resistor-limited fault current that scales with speed, so it is a property of the emulation as much as of the machines. Because the pooled null is a mixture over operating points, the 5\,\% false-alarm reading holds on average over the envelope (the share of healthy changes above the pooled 95th percentile is 0 to 16\,\% by speed for the key features). Both make the lowest monitored speed a parameter of the requirement.

With the screen applied at every setting, the MDE brackets of the key features are unchanged across window lengths of three, five and eight cycles on both machines except at the margin (the SCIG's current residual reaches the smallest inter-turn level at five and eight cycles but not at three; the PMSG's $d$-axis features, whose null quantile exceeds one at eight cycles, are screened out there), and the detectable shares move by at most 7 points except for the PMSG's $d$-axis features, which lie below $\mathrm{SDR}=1$ at every setting. Tightening $\alpha$ from 0.95 to 0.99 lowers the shares by 1 to 14 points, moves the MDE up one level for the PMSG's voltage residual and the SCIG's current residual and screens out the PMSG's $d$-axis features; relaxing it to 0.90 raises the shares by up to 10 points and moves four MDEs down one level; the orderings of the two machines are the same at every setting. At $\alpha=0.95$ the screen removes only the SCIG's duty-cycle magnitude ratio (three false alarms in nine healthy trials) and the torque features. The tap-pair bootstrap puts the median SDRs within a factor of two to four and the inter-turn shares within about $\pm15$ points (Table~\ref{tab:mde}), intervals that include the sampling variability of the null quantile.

Replacing the reference immediately before the fault by the healthy trial recorded at the same operating point at another time, a commissioning baseline, widens the null of the four key features by a factor of 1.1 to 4.6 (1.9 to 3.2 for the voltage and current residuals), lowers the median SDR of the inter-turn residuals from 6.8 to 2.4 (PMSG, voltage) and from 6.3 to 2.1 (SCIG, current) and their detectable shares from 88 and 85\,\% to 72 and 69\,\%, while inter-winding faults remain detectable in 67--93\,\% of trials. The MDEs reported here are therefore statements about a short-horizon change detector; a monitor that compares against an old baseline needs the wider null.

\section{Discussion}\label{sec:discussion}

\subsection{What the demonstration establishes about the method}

The demonstration supports four claims about the method and corrects the naive form of three of them. \emph{The design-level description of a failure mode does not fix its physical severity, and the test matrix can carry a hidden variable}: the same winding fraction produced fault currents differing by a factor of 2.3 relative to the stator current between the PMSG and the SCIG, extent and impedance were confounded on the WFSG bench, and the faulted phase rode on the nominal extent axis of all three benches, which the phasor residuals remove and the magnitude ratios do not; a comparison of alternatives must carry both axes and use features invariant to the nuisance variables of the matrix. \emph{Where a failure becomes observable is a property of the machine--drive combination, to be read with the decomposition in both forms}: ``the control structure decides'' is not supported, since both machines run the same controller and are indistinguishable through the voltage residual, and ``the SCIG wins only by a quieter null'' holds for the stator current but not for the controller quantities; a design team must know whether an alternative wins by signature or by silence, because a signature belongs to the fault physics and a null to the sensing and control chain, which a design-stage instantiation cannot simulate (Section~\ref{sec:scope}). \emph{The cheapest adequate sensor suite depends on the alternative and on the requirement, and here it changes the monitoring specification, not the choice of machine type}: at the middle inter-turn level all three alternatives meet the requirement with drive-internal quantities, at the smallest level no suite on any bench meets it with the stated power, and for inter-winding faults at the smallest level the PMSG alone needs added sensors. \emph{A monitoring design transfers across alternatives under a healthy-referenced rule, which belongs in the specification}: any referencing to healthy behaviour of the target recovered most of the performance lost in physical units, and the self-referenced rule gave the highest AUC in both directions and transferred the three machines in all six directions, the rules differing in the true-positive rate at low false-alarm rates and for the linear detector; the stronger claim that a detector transfers \emph{only} when self-referenced is not supported. The between-trial null explains the ordering, at the price that the self-referenced rule is an abrupt-onset detector that a slowly growing fault would evade; a specification should name the referencing rule and the horizon over which the reference is renewed.

\subsection{Implications for the condition monitoring of wind-turbine generators}\label{sec:implications}

Within the scope of Section~\ref{sec:threats}, a PMSG with full-power conversion should be specified with terminal voltage measurement, or with another observable of the terminal asymmetry such as the zero-sequence voltage where a neutral is accessible \citep{Urresty2012}, if inter-winding faults of the smallest tested size (2.3--3.2\,\% of a branch) are to be detected by threshold monitoring with the stated power; for inter-turn faults the voltage measurement raises the detectable share at the smallest level from 70--75 to 88\,\% without making that level a confident requirement, and from the middle level the controller's duty-cycle residual suffices. An SCIG reaches the same detectability with current transducers alone or with no added sensor. A wound-field machine with a static exciter offers the field current as a further drive-internal channel, whose 2$f_e$ ripple detected every inter-winding fault and 80\,\% of the inter-turn trials at the matching impedance; a brushless exciter would not expose it \citep{Neti2009}. A shaft torque transducer is not worth specifying for winding faults. Two industrial parameters change these statements: the ratio of current-loop bandwidth to twice the electrical frequency, which for a direct-drive multi-megawatt PMSG at a fundamental near 10\,Hz is expected to push the signature further into the controller and the voltage than in these 40--60\,Hz machines (a mechanism, not a computed prediction, since the benches' loop gains are undocumented); and the grid-connected, unregulated stator of a doubly-fed generator, whose stator and rotor currents carry the signature that rotor-current and search-coil methods exploit \citep{Shah2009}, so that whether its machine--drive combination relocates the signature at all is not established by these data.

\subsection{Limitations}\label{sec:threats}

Each alternative is represented by one physical machine, so the differences reported are differences between three machines; attributing them to topology requires replicated machines or simulated populations validated against the measured units, so the demonstration establishes the method and the mechanisms, not the population-level ranking of the topologies. The fault emulation is resistor-limited and the benches are laboratory scale: a bolted field fault is limited by the leakage reactance of the shorted turns and reaches several times the rated current, so its signature-versus-extent law, and hence every MDE, differs in kind from the one measured here, and the smallest tested fault (2.7--3.8\,\% of a branch) is larger than the one- to three-turn fault that starts an insulation failure in a large winding. The electrical frequency, the per-unit reactances and the ratio of current-loop bandwidth to twice the electrical frequency are those of the benches, whose controller gains are undocumented, so the relocation cannot be computed for another drive and Section~\ref{sec:implications} is conditional. Only winding faults and only electrical and controller observables were studied, at a fixed thermal state and without nuisance transients other than the contactor operation; the drive-internal suite that the decision table often finds cheapest is available to an OEM-integrated monitor but not to a third-party retrofit, for which three current transducers are the cheapest option. On the WFSG the fault impedance is confounded with extent, only four tap pairs per class exist at the matching impedance, and there are no healthy trials, so the screen cannot be applied and its transfer entries lack nuisance-transient negatives. Statistically, the pooled null holds its nominal false-alarm rate on average over the envelope, not per speed; the screen rests on nine healthy trials; the fixed feature is chosen on the trials it is evaluated on; the MDE is the median trial of a level and is known only as a bracket on three inter-turn levels; and the required share of 0.9 and the confidence of 0.95 are choices of the requirement. Finally, every MDE describes a short-horizon change detector; a monitor referenced to an old baseline faces a null 1.1 to 4.6 times wider on the key features (Section~\ref{sec:res-robust}).

\section{Conclusions}\label{sec:conclusion}

A measure of fault detectability that requires neither a model nor a trained detector has been proposed, the signal-to-drift ratio: a scale-free statistic calibrated on each machine's own healthy non-stationarity, from which a minimum detectable extent, a detectable share and a signature location follow for every combination of machine type, sensor suite and failure-mode class, with a reliability screen, bootstrap intervals and a decision table over the required extent, the detection power and the false-alarm level. Applied to three types of wind-turbine generator with the same tapped winding short-circuits on open benchmark data, the method showed that the same design-level fault is not the same physical fault and that the faulted phase rides on the nominal extent axis unless sequence quantities are taken as phasor residuals; that where a fault becomes visible depends on the machine--drive combination; that the cheapest sensor suite meeting a requirement depends on the alternative and on the requirement, the middle tested inter-turn level being met by drive-internal quantities on all three machines and the smallest inter-winding level requiring voltage transducers on the permanent-magnet machine alone; and that a learned detector transfers across the three machines once its features are referenced to healthy behaviour of the target machine. The findings are limited by one physical unit per alternative, laboratory scale, resistor-limited fault emulation and a single failure-mode class; the design-stage instantiation, other failure-mode classes and a cost model in place of the ordinal ranking of suites are the natural extensions, for which the released code is the starting point.

\section{Feature definitions and computation details}\label{app:appendix}

\subsection{Feature definitions}\label{app:features}

Let $f_e$ be the electrical frequency of a window of $N$ samples, estimated from the slope of the unwrapped phase of the current space vector $\tfrac{2}{3}(i_a + \mathbf{a}\, i_b + \mathbf{a}^2 i_c)$, $\mathbf{a}=e^{j2\pi/3}$, whose sign gives the phase rotation. The positive- and negative-sequence components $X_+$ and $X_-$ of the currents ($I_1=|I_+|$, $I_2=|I_-|$), terminal voltages ($V_1, V_2$) and mean-removed duty cycles ($D_1, D_2$) are the symmetrical components of the Hann-windowed complex amplitudes of the three phase signals at $f_e$. The phase-referenced negative-sequence ratio of a window is $\bar X_2 = X_-\overline{X_+}/|X_+|^2$, whose angle does not rotate with the window start; the interval mean of a residual feature is the complex mean of $\bar X_2$ over the windows of the interval, and its relative changes are $|\bar X_{2,F}-\bar X_{2,R_2}|/|\bar X_{2,R_2}|$ under fault and $|\bar X_{2,R_2}-\bar X_{2,R_1}|/|\bar X_{2,R_1}|$ in the null. The RMS unbalance, the harmonic ratios ($k=3,5,7$) and the THD (harmonics 2 to 20) of the phase currents follow the standard definitions; the synchronous-frame currents, PI outputs, voltages, torques and field current enter through the standard deviation of the mean-removed signal and its amplitudes at $f_e$ and $2f_e$ as listed in Table~\ref{tab:suitedef}; speed and DC-link features are standard deviations. On the WFSG bench the measured converter-side phase voltages serve as terminal voltages, the synchronous-frame voltages are obtained from them with the encoder angle, the commanded voltages are the controller's, and the electrical torque is computed from power and speed.

\subsection{Computation details}\label{app:computation}

\emph{Intervals.} PMSG and SCIG: reference interval 0.30--0.98\,s after the start of each record, split at 0.62\,s; contactor commanded at 1.000\,s, relay pick-up 85--90\,ms later, so the faulted interval (30\,ms after the command to 10\,ms before its release) holds about 55\,ms of healthy time, which makes the PMSG/SCIG SDRs slightly conservative; recovery windows from 0.30\,s after the release. WFSG: fault interval from the measured fault current, the first contiguous interval in which its 10\,ms RMS exceeds $\max(0.3\,\mathrm{A}, 6\sigma)$, $\sigma$ being its standard deviation over 0.05--0.40\,s; reference interval from 0.05\,s to 10\,ms before the onset, split at 0.30\,s; four trials with no complete fault window are dropped.

\emph{Bootstrap.} 2000 resamples (seed 1), the null re-estimated in every resample from a cluster resample of the machine's 25 clusters; decision table: 1000 resamples per suite, alternative, class and $\alpha$ (seed 7), the fixed feature re-selected in every resample, a suite inheriting a strictly higher probability of a cheaper subset.

\emph{Transfer.} scikit-learn histogram gradient boosting (maximum depth 3, 200 iterations, learning rate 0.08, random state 0) and logistic regression with standardisation ($C=1$); five-fold GroupKFold with one group per tap pair, healthy trials grouped by speed; the phasor residuals enter through the real and imaginary parts of $\bar X_2$; the normalising set of the self-referenced rule is the windows ending before 0.62\,s (PMSG/SCIG) or 0.30\,s (WFSG); intervals from 500 cluster resamples of the tested machine's trials.
