# Poster: Impact of Cooling Channel Shape on the Performance of Hollow Hairpin Windings

A0 portrait poster (LUT University template style) for the internal research seminar,
summarizing the ICEM 2026 and ECCE 2026 conference papers.

- `Poster_CoolingChannelShape.pptx` — editable PowerPoint poster (A0, 841 x 1189 mm)
- `Poster_CoolingChannelShape.pdf` — print-ready PDF export
- `build_poster.js` — generator script (`npm install pptxgenjs && node build_poster.js`)
- `figs/` — figures extracted from the two papers at 600 dpi + LUT logo
