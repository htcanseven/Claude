# Condensed poster (reviewer feedback)

Revision of the author's edited poster following the review comment:
"remove most of the text — keep only a few key words/phrases per paragraph,
and increase the font size of what remains."

- `HiECSs_08_2026_poster_condensed.pptx` — editable A0 poster
- `HiECSs_08_2026_poster_condensed.pdf` — print-ready export
- `condense.py` — script that produced it from the author's version

## What changed

| | before | after |
|---|---|---|
| Body text | 32 pt, full sentences | 44 pt, key phrases |
| Section headings | 40 pt | 52 pt |
| Table text | 32 pt | 36 pt |
| Chart labels | — | scaled 1.75x |
| Alignment | justified | left (avoids stretched gaps on short lines) |

Column edges were normalized (left column x=2.23", right column x=17.24",
both ending at the title's right edge) and every section re-flowed with even
vertical spacing so no gaps opened up after the text was cut.
